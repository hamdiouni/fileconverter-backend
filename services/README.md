# Services

This directory contains TypeScript/Node.js API services.

## Services

- `auth-service/` - Authentication and authorization (port 3000)
- `user-service/` - User profiles and quota management (port 3001)
- `upload-service/` - File upload handling and virus scanning (port 3002)
- `orchestrator-service/` - Conversion job orchestration (port 3003)
- `billing-service/` - Stripe billing integration (port 3004)
- `notification-service/` - Webhooks and email notifications (port 3005)
- `admin-service/` - Admin dashboards and analytics (port 3006)
