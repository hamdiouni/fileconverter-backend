# Workers

This directory contains Python-based conversion worker services.

## Workers

- `image-worker/` - Image format conversions (JPG, PNG, WEBP, TIFF, etc.)
- `video-worker/` - Video format conversions (MP4, AVI, MOV, MKV, etc.)
- `audio-worker/` - Audio format conversions (MP3, WAV, FLAC, AAC, etc.)
- `document-worker/` - Document conversions (PDF, DOCX, ODT, etc.)
- `archive-worker/` - Archive format conversions (ZIP, RAR, 7Z, etc.)
- `cad-worker/` - CAD and font conversions (DWG, DXF, TTF, OTF, etc.)
